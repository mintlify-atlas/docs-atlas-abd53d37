## What is Audora?

Audora is an open-source, self-hostable podcast and remote recording platform. It gives you studio-grade audio and video capture directly in the browser — no desktop app required. Participants join a shared room via WebRTC; each person's media is recorded locally and uploaded to your storage backend over a resilient chunked pipeline.

The platform is built as a **Turborepo monorepo** with three independently deployable services:

| Service | Technology | Purpose |
|---|---|---|
| `audora-frontend` | Next.js 15, TailwindCSS v4 | User-facing dashboard and studio recording UI |
| `audora-api` | Express, Bun | REST API, authentication, project management |
| `audora-signal` | WebSocket (ws), Bun | WebRTC signaling and room coordination |

A shared `packages/database` package (Prisma + PostgreSQL) is used across both the API and signal services.

## Key features

<CardGroup cols={2}>
  <Card title="WebRTC recording" icon="video">
    Browser-native peer-to-peer video and audio capture with local track isolation. Each participant's stream is recorded independently for maximum post-production flexibility.
  </Card>
  <Card title="Chunked uploads" icon="cloud-arrow-up">
    Media is sliced into chunks and uploaded to your S3-compatible backend as recording progresses. Uploads survive network interruptions and can be paused and resumed.
  </Card>
  <Card title="Real-time signaling" icon="signal">
    A dedicated WebSocket server handles WebRTC offer/answer/ICE exchange and broadcasts mic/camera toggle events to all room participants.
  </Card>
  <Card title="Studio management" icon="sliders">
    Each user gets a personal studio with configurable recording type (video+audio or audio-only), video quality, audio sample rate, noise reduction, and lobby settings.
  </Card>
  <Card title="Project & track model" icon="folder-tree">
    Recordings are organized into projects and tracks. Multiple participants in the same session each produce their own track, enabling multi-track editing workflows.
  </Card>
  <Card title="Auth & security" icon="shield-check">
    NextAuth.js powers authentication with credentials and Google OAuth. JWT-based meeting tokens authorize WebSocket connections to rooms.
  </Card>
</CardGroup>
